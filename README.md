# NLP-projects

Набор учебных работ по обработке естественного языка (NLP) и основам машинного обучения. Репозиторий объединяет небольшие самостоятельные эксперименты: токенизацию и сегментацию текста, морфологический анализ, стемминг, статистический анализ корпусов, нейронные сети, классификацию изображений и генерацию текста.

Большая часть материалов представлена в виде Jupyter Notebook, остальные эксперименты — в отдельных Python-скриптах. Каталоги названы номерами учебных заданий, поэтому их можно изучать независимо друг от друга.

## Быстрый старт

### 1. Клонирование репозитория

```bash
git clone https://github.com/5YYY5/NLP-projects.git
cd NLP-projects
```

### 2. Создание виртуального окружения

```bash
python -m venv .venv
```

Активация в Windows:

```powershell
.venv\Scripts\Activate.ps1
```

Активация в Linux/macOS:

```bash
source .venv/bin/activate
```

### 3. Установка основных библиотек

```bash
pip install numpy matplotlib nltk razdel natasha pymorphy3 tensorflow tensorflow-datasets jupyter
```

Набор зависимостей отличается от задания к заданию. Для запуска конкретного эксперимента устанавливайте только необходимые библиотеки.

## Как запускать материалы

### Python-скрипты

Запуск выполняется из корня репозитория:

```bash
python 2/natali.py
python 3/stemmer.py
python 4/t5.py
python 6/main.py
python 7/letters.py
python 8/drop.py
python 10/rnn_words.py
```

### Jupyter Notebook

```bash
jupyter notebook
```

После запуска Jupyter откройте нужный файл, например:

- `8/drop.ipynb` — эксперименты с Dropout;
- `9/perceptron_1.ipynb` — перцептрон;
- `12/task_vis.ipynb` — визуализация и анализ данных.

Также notebooks можно открыть непосредственно через интерфейс GitHub, но для выполнения ячеек потребуется локальное окружение или Google Colab.

## Что изучать в каждом разделе

### Токенизация и сегментация — `2/`

Сравниваются подходы к выделению токенов и предложений с использованием `razdel` и `nltk`. В тестах встречаются даты, сокращения, дефисы, числа, единицы измерения и другие сложные случаи.

### Морфологический анализ — `3/`

Показано применение Natasha, pymorphy, Snowball и MyStem. Эти инструменты позволяют разбивать текст на токены, определять части речи и грамматические признаки, приводить слова к основе и удалять стоп-слова.

### Анализ текста — `4/`

Скрипты работают с русскоязычными текстами и демонстрируют подсчёт частот букв, разделение текста на предложения, токенизацию и вычисление простых статистик: количества токенов и средней длины слов.

### Основы нейронных сетей — `6/`

`line.py` показывает обучение регрессионной модели, а `main.py` — реализацию небольшой сети для вычисления XOR и её проверку на наборах входных данных.

### Классификация изображений — `7/`, `8/`, `10/`

- `7/` — распознавание рукописных букв из EMNIST;
- `8/` — влияние числа нейронов и Dropout на качество классификации MNIST;
- `10/raspozn_cifr_svertka.py` — распознавание цифр свёрточной нейронной сетью.

### Генерация текста — `10/`

`rnn.py` предсказывает следующий символ, а `rnn_words.py` — следующее слово по трём предыдущим словам. Обе модели обучаются на корпусе `cat.txt`.

## Особенности текущей версии

1. **В проекте нет единого файла зависимостей.** Состав библиотек нужно подбирать для конкретного задания.
2. **Некоторые скрипты используют абсолютные пути Windows**, например `C:/Users/User/...`. Перед запуском таких файлов замените пути на расположение файлов в вашем компьютере.
3. **Часть кода рассчитана на интерактивный запуск.** Скрипты могут открывать графики через `matplotlib` и ожидать их закрытия.
4. **Для `3/MyStem/mystem.exe` используется Windows-исполняемый файл.** На Linux и macOS потребуется установить совместимую версию MyStem или заменить этот этап другим морфологическим анализатором.
5. **Запуск нейросетевых экспериментов может занимать значительное время** и требует установки TensorFlow.
6. **Данные загружаются автоматически** для `MNIST` и `EMNIST` при первом запуске, поэтому потребуется интернет-соединение и дополнительное место на диске.
7. Файлы `.ipynb` содержат не только код, но и сохранённый вывод ячеек. Для воспроизводимого результата рекомендуется выполнить ячейки заново сверху вниз.

## Рекомендуемый порядок изучения

1. `2/` — понять токенизацию и сегментацию.
2. `3/` — перейти к морфологии, стеммингу и стоп-словам.
3. `4/` — изучить ручные правила обработки текста и статистический анализ.
4. `6/` — посмотреть базовые нейронные сети без специализированных NLP-моделей.
5. `7/` и `8/` — познакомиться с классификацией изображений и регуляризацией.
6. `10/` — перейти к CNN, RNN и генерации текста.
7. `9/` и `12/` — изучить дополнительные notebook-эксперименты и визуализацию.

## Статус проекта

Это учебный репозиторий с независимыми лабораторными работами и экспериментами. Код предназначен прежде всего для демонстрации принципов NLP и машинного обучения, а не для использования как готовая библиотека или производственное приложение.
